# Dataset: Customer Support on Twitter

This dataset contains tweets and replies from customer support accounts on Twitter. 
It is used for intent classification, historical response retrieval, and generative AI customer support tasks.

## Source
Original source: Kaggle - [Customer Support on Twitter](https://www.kaggle.com/datasets/thoughtvector/customer-support-on-twitter)

## Local Path and Requirements
- **Expected local path**: `twcs/twcs.csv` (relative to the repository root).
- **Required filename**: `twcs.csv`.

## Version Control
The full `twcs.csv` file is approximately 500MB and contains sensitive real-world interactions. To prevent slow cloning, keep the repository small, and adhere to GitHub's file size limits, the full dataset is not committed to GitHub. It is ignored via `.gitignore`.

## How to obtain the dataset
1. Go to the Kaggle page: [Customer Support on Twitter](https://www.kaggle.com/datasets/thoughtvector/customer-support-on-twitter).
2. Download the dataset archive.
3. Extract `twcs.csv` into a folder named `twcs/` at the root of this repository.
